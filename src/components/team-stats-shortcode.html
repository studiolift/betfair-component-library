A shortcode to display team statistics for a given team.

Shortcode example

{% highlight html %} [teamStats team="90" stats="winLoseDraw|goals|over15Goals|over25Goals|over35Goals|bothTeamsToScore|shots|shotsOnTarget|corners|cards|fouls"] {% endhighlight %}
Parameter Usage Required
team The ID of the team for whom to display statistics. Yes
stats A pipe-separated list of statistics to display. Yes
