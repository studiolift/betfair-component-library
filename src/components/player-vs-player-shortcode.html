--- title: Player vs Player date: 2024-01-17 tags: shortcodes ---

A shortcode to display player statistics for two given players.

Shortcode example

{% highlight html %} [playerVsPlayer player1="2847" player2="2869"] {% endhighlight %}
Parameter Usage Required
player1 The ID of the first player. Yes
player2 The ID of the second player. Yes
