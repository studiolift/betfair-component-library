--- title: Race Card date: 2024-01-08 tags: shortcodes ---

A shortcode to display a set of runners for a particular race. The card can be customised to show if the race is still upcoming, in progress, or has completed.

Shortcode example

{% highlight html %} [raceCard race="19-november-2026/lingfield-park/30/1" title="Optional Title" runners="3"] {% endhighlight %}
Parameter Usage Required
race The title of the multiple bet Yes
title The title of the race card. If not provided, the race title will be used. No
runners The number of runners to display No, defaults to 5
view By default it shows racecard before race, and results afterwards. Options for 'upcoming' or 'result' only can be set. No
odds By default it will show odds for both Sportsbook and Exchange. Options for 'sportsbook' or 'exchange' only can be set. No
