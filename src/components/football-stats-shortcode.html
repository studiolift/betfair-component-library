A shortcode to display a table of football statistics.

Shortcode example

{% highlight html %} [goalscorers league="overall" limit="3"] [assists league="overall" limit="3"] [chancesCreated league="overall" limit="3"] [passes league="overall" limit="3"] [passes league="overall" limit="3"] [playerShots league="overall" limit="3"] [teamShots league="overall" limit="3"] [playerShotsOnTarget league="overall" limit="3"] [teamShotsOnTarget league="overall" limit="3"] [overUnder league="overall" limit="3" total="1.5"] [bothTeamsToScore league="overall" limit="3"] [corners league="overall" limit="3"] [playerCards league="overall" limit="3"] [playerYellowCards league="overall" limit="3"] [teamRedCards league="overall" limit="3"] [playerFouls league="overall" limit="3"] [playerFoulsWon league="overall" limit="3"] [teamFouls league="overall" limit="3"] {% endhighlight %}
Parameter Usage Required
league The league for which to display statistics. Yes
limit The maximum number of results to display. Yes
total The total value for over/under statistics. Yes, only for over/under statistics

Output example

Player Team League Goals Scored
Harry Kane FC Bayern German Bundesliga 36
Erling Haaland Man City English Premier League 27
Kylian Mbappé Real Madrid Spanish La Liga 25
