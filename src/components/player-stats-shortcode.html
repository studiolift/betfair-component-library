--- title: Player Stats date: 2024-01-15 tags: shortcodes ---

A shortcode to display player statistics for a given player.

Shortcode example

{% highlight html %} [playerStats player="2847" stats="goals|shots|shotsOnTarget|chancesCreated|passes|cards|fouls|foulsWon"] {% endhighlight %}
Parameter Usage Required
player The ID of the player for whom to display statistics. Yes
stats A pipe-separated list of statistics to display. Yes
