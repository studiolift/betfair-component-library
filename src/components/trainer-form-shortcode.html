A shortcode to display a form table for a particular trainer.

Shortcode example

{% highlight html %} [trainerForm url="https://betting.betfair.com/horse-racing/trainer/adam-nicol/000000056480/" title="Title"] {% endhighlight %}
Parameter Usage Required
url The URL of the trainer to display Yes
title The title to display above the trainer Yes
