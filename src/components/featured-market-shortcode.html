--- title: Featured Market date: 2024-01-01 tags: shortcodes ---

A featured market component to be used to display runners in a specific market. You can use the SBK tool to search for markets and obtain the necessary IDs.

Shortcode example

{% highlight html %} [featuredMarket layout="a" id="924.533727057" limit="3" title="Optional%20Title" intro="Some%20optional%20Intro%20text.%20Favourite%20is%20%25favourite%25" showmarkettime="yes"] {% endhighlight %}
Parameter Usage Required
layout The layout to use for the featured market. Options are 'a', 'b' or 'c' Yes
id The ID of the market to display. Example: 924.533727057 Yes
title The title of the featured market No
intro The intro text for the featured market. This can use variables to display dynamic content. No
showmarkettime Whether to display the market time. Options are 'yes' or 'no' Yes

Layout C is a special layout. It is intended for use with a parent container to handle the layout. Therefore, it does not include things like title, intro or dates.

In its basic form, Layout C consists of a series of stat links.
