--- title: Match Predictions date: 2024-01-11 tags: shortcodes ---

A shortcode to display a match prediction card with fixture information, form guides, and odds.

Shortcode example

{% highlight html %} [matchPredictions url="https://betting.betfair.com/football/predictions/english-football-league-league-one/barnsley-vs-sheffield-wednesday/21mfhrhzm4c87r2vzqwn0dedw/" showOdds="true"] {% endhighlight %}
Parameter Usage Required
url The URL of the match predictions page. Yes
showOdds True/False to determine whether to display odds for the match. Yes
