--- title: Table of Contents date: 2024-01-19 tags: shortcodes ---

A shortcode for the entry body to display a table of contents. It will automatically generate a list from any h2 headings that are present in the main content.

Shortcode example

{% highlight html %} [table_of_contents] {% endhighlight %}

Output example

  • Heading level 2 in the main content
  • Another heading level 2
  • A final heading level 2
