--- title: Upcoming Matches date: 2024-01-10 tags: shortcodes ---

A shortcode to display upcoming match cards that show teams, dates, and prediction links.

Shortcode example

{% highlight html %} [upcomingMatches league="all" days="100" matches="1" layout="a"] {% endhighlight %}
Parameter Usage Required
league The league to display upcoming matches for. Yes
days Number of days to display upcoming matches for. Yes
matches Number of matches to display. Yes
layout The layout to display the matches in. Options for a, b, c and d. No

Output example

19 Nov 2026 at 23:30

Vasco vs Internacional
View predictions
