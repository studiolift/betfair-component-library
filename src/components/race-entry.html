--- title: Race Entry date: 2024-01-01 tags: shortcodes ---

A shortcode to display a race entry in an upcoming meet.

Shortcode example

{% highlight html %} [raceEntry url="https://betting.betfair.com/horse-racing/racecards/18-november-2026/kempton-park/27/6/#palladas"] {% endhighlight %}
Parameter Usage Required
url The URL of the race entry to display Yes

Output examples

7 (8)

Palladas

  • J: Charlie Deutsch
  • T: Venetia Williams
  • F: 110-D6
  • SBK 1.91
  • EXC 2.54
