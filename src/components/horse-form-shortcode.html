A shortcode to display a form table for a particular horse.

Shortcode example

{% highlight html %} [horseForm url="https://betting.betfair.com/horse-racing/horse/palladas/000000634561/" title="Title"] {% endhighlight %}
Parameter Usage Required
url The URL of the horse to display Yes
title The title to display above the horse Yes
